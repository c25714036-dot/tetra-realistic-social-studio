# Workflows

Esta pasta guarda **especificações** e, futuramente, JSONs exportados do ComfyUI.

Não incluímos workflows de terceiros sem verificar licença e versão dos custom nodes.

Sugestão de nomes:

- `01-tetra-portrait-4x5.json`
- `02-tetra-identity-instantid-4x5.json`
- `03-tetra-photomaker-multiref-4x5.json`
- `04-tetra-photoshoot-series.json`
- `05-tetra-local-business-9x16.json`
- `06-tetra-hyperreal-ugc.json`

Ao exportar do ComfyUI, registre também em um `.md` adjacente:
- versão do ComfyUI;
- custom nodes;
- modelo/checkpoint;
- resolução;
- seed;
- sampler/scheduler;
- licença dos assets.
