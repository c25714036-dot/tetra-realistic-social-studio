# Contribuindo

## Regra de ouro

Não copie arquivos de upstreams para este repositório sem revisar licença e atribuição.

## Novos workflows

Cada workflow ComfyUI deve trazer um Markdown adjacente contendo:
- objetivo;
- dependências;
- URLs dos custom nodes;
- versões testadas;
- modelos/pesos necessários;
- licenças;
- resolução e parâmetros.

## Assets

Não versionar rostos reais ou documentos de clientes em pastas públicas.
